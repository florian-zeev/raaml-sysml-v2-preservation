# Architecture decision records

Technical decision records are stored here. A decision is accepted only when
its alternatives, evidence, decision, consequences, and validation commands
are documented.

The first required decisions cover:

1. implementation language and build system;
2. canonical fact identity;
3. SysML v2 validation;
4. UML/SysML v1 validation;
5. OCL parsing;
6. secure XML and reference resolution.
